# 🎤 Mumble Stick

**Mumble Stick** is a fun, interactive desktop buddy (shimeji-style) that brings your favorite rapper to your screen. But watch out – he's a bit of a prankster!

## ✨ Features
- **Custom Heads:** Change your buddy's head to any rapper! 🎤
- **YouTube Prank:** Occasionally "pauses" your videos (hits Spacebar) every ~30-40 seconds. 🛑
- **Interactive:** Drag him, drop him from heights, and watch him get dizzy. 💫
- **Dynamic States:** Walking, jumping, waving, and a chill "Studio Mode" (sitting).
- **Auto-Scaling:** Whatever head image you use, the script automatically resizes it to fit the body. 📏

## 📁 Project Structure
- `mumble_stick.py` - The main Python script.
- `head.png` - The active head image (needs to be in the main folder).
- `premade_heads/` - Folder with pre-made rapper heads (Lil Peep, Bones, Juice WRLD, X).
- `setup_and_run.bat` - One-click installer and launcher.

## 🚀 How to Install & Run
1. Make sure you have **Python** installed.
2. Download this repository.
3. Run **`setup_and_run.bat`**. It will automatically install the required libraries (`Pillow`, `pyautogui`) and start the app.

## 👤 Changing the Head
To switch rappers:
1. Go to the `premade_heads` folder. (or download custom head)
2. Choose your favorite rapper and copy the file.
3. Paste it into the main folder and rename it to **`head.png`**.
4. Restart the app!

## 🛠️ Requirements
- Python 3.x
- `Pillow` (PIL)
- `pyautogui`
